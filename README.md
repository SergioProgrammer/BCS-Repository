# Computer Science Bachelor Repository

This repository contains my programming assignments and practical exercises for the Bachelor of Science in Computer Science at the University of the People.

Each assignment has its own folder with the source code and any related files.

## Projects

### Workshop Feedback Manager
A Python program that cleans workshop feedback, saves and reads text files, handles file errors, and generates a summary report.

## Running the Python Programs

Open the assignment folder in your terminal and run:

python3 feedback_manager.py

Replace the filename when running a different assignment.
